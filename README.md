# BlockForge

BlockForge is an original creative-coding playground with an Explore link, searchable demo projects and studios, a Messages inbox for collaboration invitations, a Create link to the editor, and a Profile control for the local demo account.

## Navigation features

- **Explore** jumps to the community spotlight.
- **Search** opens a project/studio search dialog. The static demo currently has a small local catalog.
- **Messages** opens the invitations inbox and shows a badge for pending invites to the active demo username.
- **Create** jumps into the editor.
- **Profile** opens the local demo profile/account switcher.

These are BlockForge features with original styling and labels. Accounts, inbox messages, invites, and project content are still browser-local prototypes; they are not secure authentication or cross-device services. Real user search, messaging, and profiles require authenticated accounts and a shared backend.
